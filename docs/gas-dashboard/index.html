sales-data-cleaner

Skill
---
name: sales-data-cleaner
description: 판매 데이터 파일이 오면 마스터 구조로 정리
---
목표: 어떤 형식의 파일이든 마스터와 같은 구조로
1. 열의 의미부터 파악 (이름 · 순서가 달라도)
2. 거래처 · 제품은 참조 마스터에서 가장 가까운 값으로
3. 같은 거래로 보이는 행은 하나로
4. 수량 · 단가 · 금액이 안 맞으면 고치지 말고 표시
5. 확신이 낮은 교정은 리포트에 따로
참조: 거래처 마스터 · 05 제품카탈로그
