# 캡처 목록 — Ch5 Gem

이 폴더에 아래 이름 그대로 PNG를 넣고 `python3 src/build.py` 를 다시 돌리면 덱의 회색 자리가 실제 화면으로 바뀐다.
교육용 계정에서 찍고, 개인 이메일 · 프로필 사진 · 실제 거래처 이름이 보이면 가리거나 잘라 낸다. 16:9 가로 화면이면 가장 잘 맞는다.

| 파일 이름 | 찍을 화면 | 상태 |
|---|---|---|
| gem-01-manager.png | Gemini 왼쪽 메뉴의 Gem 관리자 | 「새 Gem」 버튼이 보이게 |
| gem-02-new.png | 새 Gem 만들기 화면 | 이름만 입력한 상태 (예: 거래처 응대 도우미) |
| gem-03-instructions.png | 같은 화면의 지침 칸 | 역할 · 입력 · 출력 · 규칙 · 예시 지침을 붙여 넣은 상태 |
| gem-04-knowledge.png | 지식 추가 메뉴 | 05 제품카탈로그 · 06 단가 기준표(Sheets) · 07 응대가이드가 붙은 상태 |
| gem-05-preview.png | 오른쪽 미리보기 | A편의점 결품 문의를 넣고 1차 회신 초안이 나온 상태 |
| gem-06-share.png | 공유 설정 창 | 팀원 보기 권한이 보이게 |
| supergem-01-builder.png | Super Gem(Gems from Labs) 흐름 편집 화면 | 단계 블록이 보이게 |
| supergem-02-run.png | Super Gem 실행 화면 | 입력 양식과 결과가 함께 보이게 |

Super Gem은 계정 · 지역에 따라 메뉴가 없을 수 있다. 없으면 두 장은 비워 두고 알려 주면 해당 장을 뺀다.
